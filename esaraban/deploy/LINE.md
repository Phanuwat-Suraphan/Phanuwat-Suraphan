# แจ้งเตือนเข้ากลุ่ม LINE ของโรงเรียน

ระบบแจ้งเตือนในเว็บมีข้อจำกัดคือ **ครูที่ไม่ได้เปิดเว็บจะไม่รู้ว่ามีหนังสือด่วนรออยู่** เรื่องด่วนที่สุด
จึงค้างได้เป็นวันโดยไม่มีใครรู้ การยิงเข้ากลุ่ม LINE ที่ครูอยู่กันอยู่แล้วเป็นช่องทางที่ถึงตัวจริงที่สุด
โดยไม่ต้องให้ใครติดตั้งอะไรเพิ่ม

## ⚠️ อ่านก่อน: LINE Notify ปิดไปแล้ว

ถ้าเคยได้ยินวิธีที่ "ขอ token อันเดียวแล้วยิงได้เลย" นั่นคือ **LINE Notify ซึ่งปิดให้บริการไปแล้วเมื่อ
31 มีนาคม 2568** ใช้ไม่ได้อีกต่อไป

ตอนนี้ต้องใช้ **LINE Messaging API** ผ่าน **LINE Official Account** แทน ซึ่งตั้งค่ายุ่งกว่าเดิมนิดหน่อย
(ประมาณ 10-15 นาที) แต่ทำครั้งเดียวจบ และ**ฟรี** สำหรับปริมาณข้อความระดับโรงเรียน

## ขั้นตอน

### 1. สร้าง LINE Official Account

1. ไปที่ <https://manager.line.biz/> → เข้าสู่ระบบด้วยบัญชี LINE ของโรงเรียน
2. กด **สร้างบัญชีทางการ (Create)** → กรอกชื่อ เช่น "สารบรรณ รร.เจ้าพ่อหลวงอุปถัมภ์ ๑"
3. เลือกประเภทเป็นหน่วยงาน/โรงเรียนตามจริง

### 2. เปิด Messaging API และเอา Channel Access Token

1. ใน LINE Official Account Manager → **ตั้งค่า (Settings)** → **Messaging API**
2. กด **ใช้ Messaging API** แล้วผูกกับ Provider (สร้างใหม่ได้ ตั้งชื่อเป็นชื่อโรงเรียน)
3. ไปที่ <https://developers.line.biz/console/> → เลือก Provider → เลือก Channel ที่เพิ่งสร้าง
4. แท็บ **Messaging API** → เลื่อนลงหา **Channel access token (long-lived)** → กด **Issue**
5. คัดลอกค่าที่ได้ → นี่คือ `LINE_CHANNEL_ACCESS_TOKEN`

> ค่านี้เป็นความลับ **ห้ามส่งให้ใครทางแชท** ใครได้ไปจะส่งข้อความในนามโรงเรียนได้ทันที
> ถ้าเผลอหลุด ให้กด **Reissue** ในหน้าเดิมเพื่อยกเลิกอันเก่า

### 3. เอา LINE Official Account เข้ากลุ่มครู แล้วหา Target ID

ระบบต้องรู้ว่าจะส่งเข้า "ที่ไหน" ซึ่งคือ `LINE_TARGET_ID` มีสองแบบให้เลือก:

**แบบ ก. ส่งเข้ากลุ่มครู (แนะนำ)**

1. ในหน้า Developers Console แท็บ **Messaging API** → ปิด **Auto-reply messages** และ **Greeting messages**
   (ไม่งั้นบอทจะตอบรกกลุ่ม) แล้วเปิด **Allow bot to join group chats**
2. เชิญ LINE Official Account เข้ากลุ่มครูของโรงเรียน (ค้นจาก LINE ID ที่แสดงในหน้า Messaging API)
3. หา **Group ID** — วิธีที่ง่ายที่สุดคือตั้ง Webhook URL ชั่วคราวชี้มาที่ระบบ แต่ถ้าไม่อยากยุ่ง ให้ใช้
   **แบบ ข.** ไปก่อน แล้วค่อยเปลี่ยนทีหลังได้

**แบบ ข. ส่งเข้าบัญชี LINE ของธุรการ/ผอ. โดยตรง (ตั้งค่าง่ายกว่า)**

1. ให้คนที่จะรับแจ้งเตือน **เพิ่มเพื่อน** กับ LINE Official Account ที่สร้างไว้
2. ในหน้า Developers Console แท็บ **Basic settings** → เลื่อนลงหา **Your user ID**
   (ของเจ้าของ Channel เอง) → คัดลอกค่าขึ้นต้นด้วย `U...`
3. ใช้ค่านั้นเป็น `LINE_TARGET_ID`

> เริ่มจากแบบ ข. ก่อนได้เลย เพราะทดสอบได้ทันทีว่าทั้งระบบทำงานถูกไหม แล้วค่อยเปลี่ยนเป็น Group ID
> ทีหลังโดยไม่ต้องแก้โค้ดอะไร

### 4. ตั้ง Environment Variables

| ตัวแปร | ค่า |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | Channel access token จากขั้นตอนที่ 2 |
| `LINE_TARGET_ID` | Group ID หรือ User ID จากขั้นตอนที่ 3 |
| `PUBLIC_BASE_URL` | ที่อยู่เว็บของคุณ เช่น `https://esaraban.onrender.com` (ไม่ตั้งก็ได้ แต่ข้อความจะไม่มีลิงก์ให้กด) |

**บน Render**: Dashboard → service → Environment → Add Environment Variable → Save Changes
(Render จะ restart ให้เอง)

### 5. ทดสอบ

1. ล็อกอินเป็น **admin** → เมนู **"💬 แจ้งเตือนเข้ากลุ่ม LINE"**
2. กด **"📨 ส่งข้อความทดสอบเข้ากลุ่ม"**
3. ถ้าเห็นข้อความในกลุ่ม/แชท แปลว่าเสร็จแล้ว — ถ้าไม่เห็น หน้านั้นจะบอกสาเหตุให้

## ระบบส่งเข้า LINE ตอนไหนบ้าง

**ส่งเฉพาะเรื่องด่วนจริง** ไม่ใช่ทุกการแจ้งเตือน:

- มอบหมายหนังสือ **ด่วนมาก / ด่วนที่สุด** ให้ใครสักคน
- เรื่องถูก **ส่งกลับแก้ไข**
- เรื่อง **ไม่อนุมัติ**

เรื่องปกติยังแจ้งในเว็บเหมือนเดิม เหตุผลคือ LINE Official Account มี**โควตาข้อความฟรีจำกัดต่อเดือน**
ถ้ายิงทุกการแจ้งเตือน โควตาจะหมดตั้งแต่ต้นเดือน แล้วเรื่องด่วนจริงๆ ปลายเดือนกลับส่งไม่ออก

ถ้าอยากปรับว่าเรื่องไหนควรยิงบ้าง แก้ที่ `lineAlert: true` ใน `src/services/workflow.js`

## ถ้าส่งไม่สำเร็จ

หน้า **"แจ้งเตือนเข้ากลุ่ม LINE"** จะแสดงสาเหตุล่าสุดให้เสมอ อาการที่พบบ่อย:

- **`LINE ตอบกลับ 401`** — token ผิดหรือถูก reissue ไปแล้ว ให้ออก token ใหม่แล้วตั้งค่าใหม่
- **`LINE ตอบกลับ 400`** — `LINE_TARGET_ID` ผิด หรือบัญชีปลายทางยังไม่ได้เพิ่มเพื่อนกับ Official Account
- **`โควตาข้อความฟรีของเดือนนี้หมดแล้ว` (429)** — รอต้นเดือนหน้า หรืออัปเกรดแพ็กเกจ
- **ไม่มีอะไรเกิดขึ้นเลย** — ยังไม่ได้ตั้ง environment variable หรือยังไม่ได้ redeploy

## ความปลอดภัย

- ข้อความที่ส่งมีแค่ **เลขที่หนังสือ ชื่อเรื่อง ชื่อผู้รับ และลิงก์** ไม่มีเนื้อหาในไฟล์แนบ
- คนที่กดลิงก์ยัง**ต้องล็อกอินก่อน**ถึงจะเปิดเอกสารได้ ลิงก์ไม่ใช่ทางลัดข้ามการตรวจสิทธิ์
- แต่ชื่อเรื่องหนังสือก็เป็นข้อมูลอย่างหนึ่ง — ถ้ากลุ่ม LINE มีคนนอกโรงเรียนอยู่ด้วย ควรใช้ **แบบ ข.**
  (ส่งเข้าบัญชีธุรการ/ผอ. โดยตรง) แทนการส่งเข้ากลุ่ม
