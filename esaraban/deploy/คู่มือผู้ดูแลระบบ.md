# คู่มือผู้ดูแลระบบสารบรรณอิเล็กทรอนิกส์

เอกสารนี้เขียนให้ "คนที่ต้องดูแลระบบนี้ต่อไป" อ่านคนเดียวแล้วทำได้ ไม่ต้องถามใคร
ถ้ามีอะไรขัดกับที่จำได้ ให้เชื่อเอกสารนี้ เพราะเขียนจากสิ่งที่เกิดขึ้นจริงตอนติดตั้งใช้งาน

---

## ระบบนี้ต้องพึ่งอะไรบ้าง

**ไม่ต้องพึ่งเครื่องมือ AI หรือบริการของผู้พัฒนาใดๆ ทั้งสิ้น** ระบบทำงานได้ด้วยตัวเองเต็มรูปแบบ

| สิ่งที่ใช้ | จำเป็นไหม | หมายเหตุ |
|---|---|---|
| Node.js 22.5 ขึ้นไป | **จำเป็น** | เป็นตัวรันระบบ |
| ไลบรารีจากภายนอก (npm) | **ไม่มีเลย** | `package.json` มี `"dependencies": {}` จริงๆ — ไม่มีอะไรให้อัปเดตตามหรือหมดอายุ |
| Google Drive | ไม่บังคับ | ใช้เก็บไฟล์แนบและสำรองฐานข้อมูล — **จำเป็นมากถ้าโฮสต์ไม่มีดิสก์ถาวร** |
| LINE Official Account | ไม่บังคับ | ใช้ส่งแจ้งเตือน ไม่ตั้งก็ใช้งานทุกอย่างได้ตามปกติ |
| chromium + qpdf | ไม่บังคับ | เฉพาะการประทับตรา/ลายเซ็นลงในไฟล์ PDF จริง |
| tesseract | ไม่บังคับ | เฉพาะปุ่มอ่านข้อความจากไฟล์อัตโนมัติ (OCR) |

ระบบเชื่อมต่อออกอินเทอร์เน็ตไปแค่ **LINE** กับ **Google** เท่านั้น ซึ่งทั้งสองอย่างเป็นบัญชีของโรงเรียนเอง
ถ้าปิดทั้งสองอย่าง ระบบยังลงทะเบียนหนังสือ เสนอ อนุมัติ ลงนาม ค้นหา และออกรายงานได้ครบทุกอย่าง

## สามเรื่องที่ทำให้ระบบพังบ่อยที่สุด

### 1. ดิสก์ไม่ถาวร — ข้อมูลหายทุกครั้งที่ deploy

โฮสต์แบบฟรีหลายเจ้า (รวมถึง Render แผนฟรี) ใช้ดิสก์ชั่วคราว **ทุกครั้งที่ deploy ใหม่หรือเซิร์ฟเวอร์
รีสตาร์ท ไฟล์ฐานข้อมูลจะถูกล้างทิ้งทั้งหมด** ทั้งทะเบียนหนังสือ ไฟล์แนบ ใบลา และรหัสผ่านที่ทุกคนตั้งไว้

ที่แย่กว่านั้นคือเครื่องแบบฟรี**หลับเองเมื่อไม่มีคนใช้ประมาณ 15 นาที** แล้วตื่นมาใหม่ — เท่ากับรีสตาร์ท
วันละหลายครั้งโดยไม่มีใครสั่ง

**วิธีรับมือ:** เชื่อม Google Drive ให้ทำงานจริง ระบบจะสำรองขึ้น Drive ทุก 5 นาที (และตอนกำลังปิด)
แล้ว**กู้คืนกลับมาเองอัตโนมัติ**ตอนเปิดเครื่องใหม่ อย่างมากเสียข้อมูลแค่ 5 นาทีสุดท้าย

**วิธีตรวจว่าปลอดภัยจริงหรือยัง:**
1. เข้าหน้าแรกด้วยบัญชีผู้ดูแล — ถ้ามีแถบ **แดง** ว่า "ยังไม่ได้เชื่อมต่อ Google Drive" แปลว่ายังไม่ปลอดภัย **ห้ามเอาหนังสือจริงเข้าระบบ**
2. เข้า `ระบบ → สำเนาสำรองข้อมูล` แล้วดูว่ามีสำเนาของวันนี้ขึ้นจริงไหม
3. หน้า `ระบบ → แจ้งเตือนเข้าไลน์` จะมีแถว "ฐานข้อมูลชุดนี้เริ่มใช้เมื่อ ..." ขึ้นเฉพาะตอนที่ฐานข้อมูลเป็นของใหม่ — ถ้าเห็นแถวนี้แปลว่าเพิ่งโดนล้างไป

ทางออกถาวรคือย้ายไปโฮสต์ที่มีดิสก์จริง (ดู `deploy/ORACLE_CLOUD.md` ซึ่งฟรีและมีดิสก์ถาวร)

### 2. โหมดทดสอบเปิดค้างไว้ — รหัสผ่านที่ตั้งเองจะถูกล้างทุกครั้งที่รีสตาร์ท

ถ้าตั้ง `TEST_MODE_PASSWORD` ไว้ ระบบจะ**ตั้งรหัสผ่านและ PIN ของทุกบัญชีใหม่ให้เหมือนกันหมด
ทุกครั้งที่เริ่มทำงาน** อาการที่เกิดจริงคือ "เปลี่ยนรหัสผ่านแล้ว วันรุ่งขึ้นเข้าไม่ได้"

ตอนนี้ระบบจะ**ปฏิเสธ**การเปลี่ยนรหัสผ่าน/PIN ระหว่างเปิดโหมดนี้ พร้อมบอกเหตุผล ไม่ปล่อยให้เปลี่ยน
แล้วแอบล้างทิ้งอีก — **พอทดสอบเสร็จให้ลบตัวแปรนี้ออกแล้ว restart ทันที**

### 3. LINE อยู่ในโหมดตอบกลับอัตโนมัติ — ข้อความจะไม่ถูกส่งมาถึงระบบเลย

อาการคือส่งรหัสเชื่อมบัญชีเข้าแชทแล้วเงียบสนิท ทั้งที่หน้าตั้งค่าขึ้นเขียวครบ

ให้กดปุ่ม **🩺 ตรวจการตั้งค่าฝั่ง LINE เดี๋ยวนี้** ที่หน้า `ระบบ → แจ้งเตือนเข้าไลน์` ระบบจะถาม LINE
ตรงๆ แล้วบอกว่าติดตรงไหน — สาเหตุที่พบบ่อยที่สุดคือบัญชีทางการอยู่ในโหมดแชท ซึ่งต้องไปปิดที่
`manager.line.biz` (**ไม่ใช่** `developers.line.biz` — คนละหน้ากัน และคนตั้งค่ามักไปผิดที่)

## ตัวแปรตั้งค่าทั้งหมด

ตั้งที่ผู้ให้บริการโฮสต์ (Render: Environment) แล้ว restart หนึ่งครั้ง

### พื้นฐาน

| ตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `PORT` | 3000 | พอร์ตที่ระบบเปิดรอ |
| `DB_PATH` | `data/esaraban.db` | ที่เก็บไฟล์ฐานข้อมูล |
| `SESSION_SECRET` | ค่าตัวอย่าง | **ต้องตั้งเป็นค่าสุ่มของตัวเองเสมอ** ใช้เซ็นคุกกี้เซสชัน |
| `PUBLIC_BASE_URL` | เดาจาก request | ตั้งเมื่อใช้โดเมนของโรงเรียนวางหน้าโฮสต์อีกที |
| `PRIVACY_CONTACT_EMAIL` | — | อีเมลติดต่อบนหน้านโยบายความเป็นส่วนตัว |
| `SCHOOL_NAME` | โรงเรียนวัดเสาหิน | ชื่อโรงเรียนบนหัวหนังสือ/ตราประทับ/ใบลา — ปกติตั้งที่หน้า `ระบบ → ตั้งค่าโรงเรียน` ได้เลย แต่ตั้งเป็น env var ไว้ด้วยจะ**รอดจากการล้างดิสก์** ส่วนค่าที่ตั้งในหน้าเว็บจะหายไปพร้อมฐานข้อมูล |
| `SCHOOL_SHORT_NAME` / `SCHOOL_INITIALS` | — | ชื่อย่อ/อักษรย่อ ใช้บนหน้าจอมือถือและโลโก้มุมซ้าย |

### บัญชีผู้ใช้

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `SELF_REGISTRATION` | ตั้งเป็น `off` เพื่อปิดหน้าลงทะเบียนด้วยตัวเองของครู (ค่าเริ่มต้นคือเปิด) |
| `ADMIN_RESET_PASSWORD` | **ทางเข้าฉุกเฉินเมื่อผู้ดูแลลืมรหัส** ตั้งรหัสชั่วคราวแล้ว restart จากนั้นเข้าระบบแล้วตั้งรหัสจริง — **เสร็จแล้วลบตัวแปรนี้ทันที** |
| `ADMIN_RESET_CODE` | เลือกว่าจะกู้บัญชีไหน (ค่าเริ่มต้น `admin`) |
| `TEST_MODE_PASSWORD` | ตั้งรหัสทุกบัญชีให้เหมือนกันเพื่อทดสอบ — **ห้ามเปิดค้างตอนใช้งานจริง** (ดูข้อ 2 ข้างบน) |
| `TEST_MODE_PIN` | PIN ของโหมดทดสอบ (ค่าเริ่มต้น `123456`) |

### Google Drive (เก็บไฟล์ + สำรองข้อมูล)

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `STORAGE_PROVIDER` | ตั้งเป็น `google_drive` เพื่อเปิดใช้ |
| `GOOGLE_OAUTH_CLIENT_ID` / `GOOGLE_OAUTH_CLIENT_SECRET` | จาก Google Cloud Console |
| `GOOGLE_OAUTH_REFRESH_TOKEN` | ได้จากการกดเชื่อมต่อที่หน้า `/admin/google-drive` |
| `BACKUP_INTERVAL_MINUTES` | ความถี่การสำรอง (ค่าเริ่มต้น 5 นาที) |
| `BACKUP_KEEP_RECENT` / `BACKUP_KEEP_DAYS` | เก็บสำเนาไว้กี่ชุด/กี่วัน |
| `EPHEMERAL_DISK` | `1` หรือ `0` เพื่อบอกระบบตรงๆ ว่าดิสก์ถาวรหรือไม่ (ปกติเดาเองได้) |

ขั้นตอนเชื่อมต่อแบบละเอียดอยู่ใน `deploy/GOOGLE_DRIVE.md`

### LINE

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | ใช้**ส่ง**ข้อความออกไป |
| `LINE_CHANNEL_SECRET` | ใช้ตรวจว่า webhook ที่เข้ามาเป็นของ LINE จริง |
| `LINE_OA_BASIC_ID` | เช่น `@123abcde` ใช้ทำลิงก์เพิ่มเพื่อน |
| `LINE_LIFF_ID` / `LINE_LOGIN_CHANNEL_ID` | เปิดระบบในแอป LINE ได้เลย ไม่ต้องพิมพ์รหัสผ่าน (ไม่บังคับ) |

> ⚠️ **สามค่าแรกเป็นความลับ** ใครถือไปส่งข้อความในนามโรงเรียนได้ทันที
> **ห้ามส่งให้ใครทางแชท และห้ามอยู่ในภาพหน้าจอ** ถ้าหลุดไปแล้วให้กด Issue ออกค่าใหม่ที่
> LINE Developers **แล้วเอาค่าใหม่มาแก้บนเซิร์ฟเวอร์ด้วย** ไม่งั้นการเชื่อมบัญชีจะเงียบทั้งระบบ

### การประทับตราลงไฟล์ PDF

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `CHROME_BIN` | ชื่อไบนารีของ chromium (ค่าเริ่มต้น `chromium`) |

ต้องติดตั้ง `chromium` และ `qpdf` บนเซิร์ฟเวอร์ — บน Render ต้องใช้ Docker runtime (มี `Dockerfile` ให้แล้ว)

> การประทับต้องเปิด chromium ขึ้นมาเรนเดอร์ ซึ่งกินหน่วยความจำหลักร้อยเมกะไบต์
> **บนเครื่องที่ RAM น้อย (เช่น 512MB) อาจถูกระบบฆ่าทิ้งกลางคัน** ถ้าเกิดขึ้น ระบบจะขึ้นแถบแดง
> ค้างไว้ที่หน้าเอกสารและหน้าแรกของธุรการว่า "ไฟล์นี้ยังไม่มีความเห็น/ลายเซ็นบนตัวหนังสือ"
> — **อย่าเพิ่งส่งไฟล์นั้นออกไปหรือเก็บเข้าแฟ้ม**

## งานประจำที่ต้องทำ

| ทำเมื่อไหร่ | ทำอะไร |
|---|---|
| ทุกวัน | เปิดหน้าแรกด้วยบัญชีผู้ดูแล ดูว่ามีแถบแดงขึ้นไหม (สำรองข้อมูล / ไฟล์ที่ประทับไม่สำเร็จ) |
| เมื่อมีคนขอใช้งาน | `ระบบ → คำขอลงทะเบียน` — **ยืนยันตัวตนกับเจ้าตัวก่อนกดอนุมัติทุกครั้ง** และเลือกบทบาทให้ถูก |
| ทุกสัปดาห์ | `ระบบ → สำเนาสำรองข้อมูล` ดูว่าสำเนายังเดินอยู่ |
| เมื่อมีคนลาออก/ย้าย | `ระบบ → จัดการผู้ใช้` แล้วปิดบัญชี (ไม่ใช่ลบ — ลบแล้วลายเซ็นบนหนังสือเก่าจะอ้างอิงไม่ได้) |
| เมื่อมีคนลืมรหัส | `ระบบ → จัดการผู้ใช้ → ตั้งรหัสใหม่` ระบบออกรหัสชั่วคราวให้ แล้วบังคับให้เจ้าตัวตั้งเองทันทีที่เข้ามา |

## เมื่อมีปัญหา

| อาการ | สาเหตุที่พบบ่อยที่สุด | ทำยังไง |
|---|---|---|
| เปลี่ยนรหัสผ่านแล้วเข้าไม่ได้ | `TEST_MODE_PASSWORD` เปิดค้าง | ลบตัวแปรออกแล้ว restart |
| ผู้ดูแลลืมรหัส เข้าไม่ได้เลย | — | ใช้ `ADMIN_RESET_PASSWORD` |
| บัญชีถูกล็อก | กรอกผิดครบ 5 ครั้ง (ล็อก 15 นาที) | รอ 15 นาที หรือให้ผู้ดูแลกด "ตั้งรหัสใหม่" ซึ่งปลดล็อกให้ด้วย |
| ส่งรหัสเชื่อมบัญชีเข้าไลน์แล้วเงียบ | โหมดแชท / ยังไม่เปิด Use webhook / secret ไม่ตรง | กดปุ่ม 🩺 ตรวจการตั้งค่าฝั่ง LINE |
| เชื่อมบัญชีไลน์แล้วแต่ไม่ได้รับข้อความ | โทเคนขาออกมีปัญหา | โปรไฟล์ของฉัน → 📨 ส่งข้อความทดสอบหาตัวเอง |
| ข้อมูลหายหลัง deploy | ดิสก์ไม่ถาวร + Drive ไม่ทำงาน | ดูข้อ 1 ข้างบน |
| เปิดเว็บครั้งแรกช้ามาก (~50 วินาที) | เครื่องแบบฟรีหลับอยู่ | ปกติ ไม่ใช่ความผิดพลาด — เปิดทิ้งไว้รอสักครู่ |

**ที่ตรวจสอบย้อนหลังได้เสมอ:** `ระบบ → Audit Log` บันทึกทุกการกระทำแบบลบไม่ได้ ค้นด้วยชื่อการกระทำ
ได้ เช่น `line_linked`, `password_changed`, `registration_approved`, `document_voided`

## การย้ายโฮสต์ / สำรองแบบเอาไฟล์ไปเลย

ทั้งระบบคือ **โฟลเดอร์เดียว** ไม่มีอะไรฝังอยู่ที่อื่น

```
esaraban/
├── data/esaraban.db   ← ทะเบียนหนังสือทั้งหมดอยู่ในไฟล์เดียวนี้
├── uploads/           ← ไฟล์แนบ (เมื่อไม่ได้ใช้ Google Drive)
└── (โค้ดที่เหลือ)
```

ก๊อปสองอย่างนี้ไป แล้วรัน `node server.js` บนเครื่องใหม่ที่มี Node 22 ก็ได้ระบบเดิมทั้งชุด
ไฟล์ `.db` เปิดอ่านได้ด้วยโปรแกรม SQLite ทั่วไป — ข้อมูลไม่ได้ถูกล็อกไว้กับใคร
