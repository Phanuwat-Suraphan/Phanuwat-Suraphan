# ตราประทับจริงของโรงเรียน (ภาพอ้างอิงสำหรับดีไซน์)

ไฟล์ในโฟลเดอร์นี้คือภาพถ่ายตรายางจริงที่ธุรการโรงเรียนใช้งานอยู่ ใช้เป็นต้นแบบตอนออกแบบ
`src/services/pdfStamp.js` (กล่องที่ฝังลงไฟล์ PDF จริง) และ `.doc-stamp`/`.doc-decision-box` ใน
`public/style.css` (กล่องที่ซ้อนแสดงตอนดูตัวอย่างในเว็บ)

- `received-stamp.png` — ตรา "ลงรับ" (เลขรับ/วันที่/เวลา) ของธุรการ
- `director-decision-box.png` — กล่องความเห็นของผู้อำนวยการตัวจริง (มีชื่อ-ตำแหน่งพิมพ์ไว้ในตรายางเลย)
- `acting-director-decision-box.png` — กล่องความเห็นสำหรับ "รักษาการในตำแหน่งผู้อำนวยการสถานศึกษา"
  (ใช้ตอนไม่มีผู้อำนวยการตัวจริงอยู่ ตรงกับฟีเจอร์ "มอบหมายรักษาการแทน" ในระบบ)

## การจัดวางบนหน้ากระดาษ

ตรา "ลงรับ" อยู่มุมขวาบน ส่วนแถบล่างของเอกสารแบ่งเป็น 3 ช่องเรียงจากซ้ายไปขวา **ขอบบนตรงกันทั้งสามช่อง**
(ค่าคงที่ `DECISION_MAX_TOP_PERCENT` = 72% ของความสูงหน้า):

```
┌─────────────────────────────────────────── A4 ───────────────────────────────────────────┐
│                                                            ┌──────────────────┐          │
│                                                            │ ตราลงรับ (ธุรการ) │          │
│                                                            └──────────────────┘          │
│                                                                                          │
│                                     (เนื้อหาหนังสือ)                                      │
│                                                                                          │
│  ── 72% ──────────────────────────────────────────────────────────────────────────────   │
│  เรียนผู้อำนวยการโรงเรียน        ทราบ            ┌─ กรอบตราปั๊ม ผอ. ──┐                     │
│  (ความเห็นธุรการ)               (ลายเซ็น)       │ ☑ ทราบ ☐ อนุญาต ... │                    │
│  (ลายเซ็น)                     (ชื่อผู้รับ)      │ เห็นควรให้ ...       │                    │
│  (ชื่อ) ตำแหน่ง......                            │ (ลายเซ็น ผอ.)       │                    │
│                                                └────────────────────┘                    │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

- **ความเห็นธุรการ (ซ้ายล่าง)** — เฉพาะบทบาทธุรการ 3 ส่วนตายตัว: บรรทัดแรก "เรียนผู้อำนวยการโรงเรียน"
  บรรทัดถัดมาคือความเห็น ปิดท้ายด้วยลายเซ็น + ชื่อ + "ตำแหน่ง......"
- **ทราบ (กลาง)** — ลายเซ็นของ**ผู้ได้รับเอกสาร**คนนั้นๆ ในสาย workflow (มีหลายคนก็เรียงลงมาทีละแถว)
- **กรอบตราปั๊ม ผอ. (ขวาล่าง)** — เฉพาะผู้อำนวยการตัวจริง/ผู้รักษาการแทนเท่านั้น

ค่าเหล่านี้เป็นแค่**ตำแหน่งตั้งต้น** — ทุกช่องลากย้ายเองได้ก่อนกดปุ่มดำเนินการ ตำแหน่งที่ลากไว้จะถูกส่งไป
ใช้ประทับจริงในรอบนั้น (ดู `DEFAULT_*_X_PERCENT` ใน `src/services/pdfStamp.js`)

**หมายเหตุสำคัญ**: ตรายางจริงพิมพ์ชื่อ-ตำแหน่งคนตายตัวไว้ในเนื้อตรา (เพราะเป็นตรายางทางกายภาพ) แต่ในระบบนี้
ต้องดึงชื่อ-ตำแหน่งจากบัญชีผู้ใช้ที่ล็อกอินอยู่แบบไดนามิกเสมอ (เผื่อเปลี่ยนตัวผู้อำนวยการ/ผู้รักษาการแทนในอนาคต)
จึงไม่ได้เอาไฟล์ภาพเหล่านี้ไปฝังเป็นภาพนิ่งตรงๆ ในระบบ — ใช้เป็นต้นแบบสำหรับจัดวาง/ข้อความ/สไตล์เท่านั้น
ส่วนชื่อ-ตำแหน่งจริงในระบบจะดึงจากตาราง `users` ของบัญชีที่ทำรายการเสมอ
